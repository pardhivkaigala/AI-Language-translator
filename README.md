# AI-Language-translator


AI-Powered Real-Time Language Translator 🌍🤖
Developed an intelligent language translation web application using HTML, CSS, and JavaScript. The application enables users to translate text between multiple languages in real time, helping break language barriers and promote global communication. Integrated a translation API to provide fast and accurate translations through a simple, responsive, and user-friendly interface. This project strengthened my skills in API integration, asynchronous JavaScript, frontend development, and building AI-assisted applications for real-world communication challenges.
